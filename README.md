# PeopleCreeper™

> Because privacy is overrated.

## About

PeopleCreeper is an early-2000s-inspired social networking platform built from scratch as part of Project Rebirth.

## Project Rebirth

Project Rebirth is my personal initiative to rebuild and strengthen my software development skills through practical projects.
