# PeopleCreeper™ — Project Plan

> Because privacy is overrated.

**Current Version:** `v0.0.1`  
**Status:** Planning

## Project Goal
PeopleCreeper™ is an early-2000s-inspired social networking platform
built from scratch as part of Project Rebirth.

The goal of this project is to rebuild and strengthen my software
development skills through the practical development of a complete
web application.

## MVP
The Minimum Viable Product (MVP) will provide the core functionality
needed to operate as a basic social networking platform.

PeopleCreeper MVP allows users to create accounts, maintain
profiles, connect with friends, create text posts, and view
posts from themselves and their friends.

### Core Features

- **User Accounts**
  Allows users to register, log in, and log out of their PeopleCreeper account.
- **User Profiles**
  Provides each user with a personal profile containing basic information and account details.
- **Friends**
  Allows users to find other users, send and manage friend requests, and maintain a list of friends.
- **Posts**
  Allows users to create and delete text-based posts that can be shared with their friends.
- **Home Feed**
  Displays posts from the user and their friends in a centralized feed.
- **Post Management**
  Ensures users can manage their own posts while preventing unauthorized users from modifying or deleting them.
- **Access Control**

## MVP Exclusions
The following features are intentionally excluded from the initial
MVP and may be considered for future versions.

- Likes
- Comments
- Photo uploads
- Notifications
- Private messaging
- Real-time chat
- Groups
- Advanced search
- Admin dashboard
- Email verification
- Password recovery

## Planned Pages
The initial application is expected to contain the following pages.

- Landing Page
- Registration
- Login
- Home
- Profile
- Edit Profile
- Friends

Additional pages may be introduced as development progresses.

## Initial Database Structure
The initial database is expected to contain the following core tables.

- `users`
- `profiles`
- `friendships`
- `posts`

The exact columns and relationships will be designed before implementation.
